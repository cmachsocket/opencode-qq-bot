# 收藏表情（表情包）

插件支持 QQ 的**收藏表情**（NapCat 里叫自定义表情）：给每个收藏表情起一个中文标签，
之后让模型按**编号**把表情发回聊天。

## 前提

- NapCat 已连接，并且登录账号在 QQ 客户端里收藏过表情（收藏表情 = QQ 客户端「表情 → 收藏」）。
- 插件只处理**收藏表情**，不涉及商城表情包（marketplace / mface）。
- 收藏表情的原始数据在 NapCat 侧，插件不保存副本。

## 命令

在 OpenCode 里输入斜杠命令：

```
/emoji-label all     重新标注全部收藏表情
/emoji-label inc     只标注还没有标签的收藏表情
/emoji-label list    列出收藏表情的编号与标签
```

- 命令没有 TUI 回显，所有结果都通过 **QQ 消息**发出去。
- 结果优先发给命令所在会话绑定的群聊 / 私聊；会话没有绑定目标时，发给配置里的第一个目标
  （先群聊后私聊，顺序同 `groups` / `users`）。
- `all` / `inc` 在后台执行，边跑边发进度（每 5 个一条），结束时发汇总。
- 同一时间只跑一个标注任务，重复触发会收到提示。

## 标签生成链路

1. 用 OneBot 动作 `fetch_custom_face_detail` 读收藏表情列表。
2. 下载图片到受控临时目录（复用和普通图片一样的临时文件存储）。
3. 把图片作为文件引用投进一个**专用的标注会话**：
   - 这个会话不绑定任何 QQ 目标，因此不会带上「必须调用 `qq_send_message`」的角色守则；
   - 会话 ID 存在插件存储里，标签会话标记为 `qqEmojiLabelSession`，重启后继续复用。
4. 提示词要求模型只回一行中文名字，不加标点、不加解释、不调用工具。
5. 监听 `session.text.ended` 事件拿到这轮回复，取最后一段文本。
6. 清洗：取第一行、去掉列表符号与引号、只保留文字和数字、按码点截断到 **12 个字**。
7. 用 `set_custom_face_desc` 把标签写回 NapCat 的 `desc` 字段。

标签的唯一存放位置是 NapCat 的 `desc` 字段，插件不落本地文件，
所以在 QQ 客户端里也能看到同一个标签。

标注开始前插件会先给收藏表情分配编号，所以汇总消息里每个标签前面都带着
可以直接用来发送的编号。

## 编号与标签

每个收藏表情都有一个编号，**由插件自己维护**，从 1 开始按首次出现的顺序分配，
并保存在插件存储里。编号只是发图片时的句柄，真正的身份依据是**图片 md5**：

- 身份键优先用 `md5`（同一张图就是同一个收藏表情），缺失时退到 `res_id`，再退到 `emo_id`；
- NapCat 的 `emo_id` 变了、`res_id` 变了、列表顺序变了，编号都不变；
- `md5` 相同的记录按同一张图处理，只保留一条；
- 收藏表情被删掉后，它的编号不会再分配给别人；
- 标签只用来让人和模型看懂这个表情是什么，发图只认编号。

拿到编号和标签的两种方式：

- 斜杠命令 `/emoji-label list`，结果按 QQ 消息发出：

  ```
  收藏表情（编号即发送用的 id，共 3 个）
  1. 震惊的可达鸭
  2. 闭眼恬静少女
  3. （未标注）
  ```

- 工具 `qq_favorite_list`，直接返回同样的文本，不发消息。

## 发送收藏表情

模型用 `qq_send_sticker` 工具发送，参数是**编号**：

```jsonc
{ "id": 1 }
```

插件按编号取出收藏表情，用 **image 段 + `sub_type=1`（KCUSTOM）** 加上收藏表情的
CDN 直链发送 —— OneBot 协议没有单独的「收藏表情」消息段，NapCat 靠 `sub_type`
区分普通图片和收藏表情。

编号不存在时，错误信息里会列出当前可用的编号和标签。

## 已知限制

- 一次最多读取 48 个收藏表情（`fetch_custom_face_detail` 的 `count` 上限）。
- 编号存在插件存储里；清掉插件存储或换账号后，编号会从头分配。
- 标签会话每张表情最多等 60 秒，超时算失败，不写标签。
- 表情的 `emoId` / `res_id` / `md5` 缺失时无法写标签，会跳过并记日志。
- 身份键（编号的认回依据）以 `md5` 为准；`md5` 缺失时退到 `res_id`（仍稳定），
  再退到 `emo_id`（不稳定，NapCat 侧重排会让编号错位）。实测 NapCat 返回的收藏表情都带 `md5`。
- 收到别人发来的收藏表情时，提示词里保留 NapCat 给的摘要（例如 `[动画表情]`）；
  官方系统表情（`face` 段）渲染成 `[得意]` 这样的名称，未收录的 ID 回退成 `[表情:ID]`。
